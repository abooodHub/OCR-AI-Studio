# OCR-AI Studio

**الإصدار الحالي: 1.0.0**

إعادة بناء احترافية لتطبيق تحويل ترجمات PGS وVobSub وBDN وDVB وXSUB وDVD الصورية إلى نص باستخدام
LM Studio أو Ollama أو Unsloth وموديلات Vision مثل `qwen/qwen2.5-vl-7b`.

## التشغيل

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

على Windows يمكن تشغيل `run_app.bat` بعد تثبيت المتطلبات.

يمكن تنزيل نسخة Windows الجاهزة من صفحة
[Releases](https://github.com/abooodHub/OCR-AI-Studio/releases). يحتاج الإصدار الحالي إلى
توفر `FFmpeg` و`FFprobe` في `PATH`. يحتاج استخراج VobSub المضمّن كذلك إلى أدوات
`mkvmerge` و`mkvextract` من MKVToolNix.

## استخدام Unsloth

شغّل Unsloth Studio وخادم الاستدلال المحلي، ثم اختر `Unsloth` من صف المحرك داخل الواجهة:

```powershell
unsloth studio -p 8888
```

العنوان الافتراضي داخل التطبيق هو `http://127.0.0.1:8888/v1`. أدخل مفتاح API الذي يعرضه
Unsloth في الحقل المخفي؛ يبقى المفتاح في ذاكرة جلسة التطبيق ولا يُكتب في `settings.json`.
يمكن بدلًا من ذلك تمريره عبر متغير البيئة `UNSLOTH_API_KEY`.

## الاتصال بمحرك Vision

تعمل الواجهة في صفحة عربية RTL واحدة: اختر LM Studio أو Ollama أو Unsloth، ثم اضغط
**فحص الاتصال وجلب الموديلات**. تظهر موديلات Vision المناسبة داخل قائمة واحدة بلا تفاصيل تقنية
مزدحمة. توجد قيمة عنوان API والمفتاح والمهلة داخل نافذة **إعدادات الاتصال** فقط.

لا يبحث التطبيق عن ملفات تشغيل LM Studio/Ollama/Unsloth ولا يبدأ أو يوقف أي برنامج خارجي.
يشغّل المستخدم الخادم والموديل يدويًا، ويفحص OCR-AI Studio اتصال API في الخلفية قبل المعالجة.

يحتوي المشروع على نقطة تشغيل واحدة فقط هي `main.py`. يستخدم المشغل `pythonw.exe`
لتشغيل الملف نفسه دون إظهار نافذة أوامر إضافية.

## بنية المشروع

```text
OCR-AI-sub-mks/
├── main.py                 # نقطة التشغيل الوحيدة
├── ocr_ai_studio/          # كود التطبيق
│   ├── ai/                 # الاتصال بخوادم Vision وقراءة الموديلات
│   ├── config/             # إعدادات المستخدم
│   ├── domain/             # نماذج البيانات
│   ├── exporters/          # SRT وVTT وASS وTXT
│   ├── media/              # FFmpeg وPGS وVobSub وBDN
│   ├── persistence/        # مشاريع SQLite والاستئناف
│   ├── processing/         # خط المعالجة والصور
│   └── ui/                 # واجهة PySide6 RTL
├── packaging/              # إعداد بناء ملف EXE
├── tests/                  # الاختبارات الآلية
├── pyproject.toml          # تعريف الحزمة وأدوات الجودة
├── requirements.txt        # اعتماديات التشغيل
├── setup_env.bat           # إعداد البيئة
└── run_app.bat             # تشغيل الواجهة على Windows
```

## خصائص الإصدار الحالي

- واجهة PySide6 عربية RTL من صفحة واحدة مع سحب وإفلات وإعدادات اتصال مختصرة.
- إضافة عدة ملفات دفعة واحدة، تحليلها في الخلفية، وتشغيلها تلقائيًا بالتتابع.
- عرض عدد الصور والأسطر والوقت المنقضي والوقت المتبقي أثناء المعالجة.
- إظهار مسار النتيجة وزر فتح مجلد الحفظ بعد اكتمال المهمة.
- اختبار أول ثلاث صور قبل متابعة التحويل الطويل مع عرض النص والوقت المتوقع.
- تحديث ملف `.partial` دوريًا أثناء OCR، وليس فقط عند نهاية المهمة الفاشلة.
- فحص بنية التوقيت قبل اعتماد الملف النهائي مع تقرير مختصر بعد الانتهاء.
- قائمة انتظار محفوظة لمعالجة عدة ملفات بالتتابع واستعادتها تلقائيًا بعد إعادة فتح التطبيق.
- استئناف تلقائي للإطارات المنجزة بعد إغلاق التطبيق أو انقطاع خادم Vision.
- إعادة OCR تلقائيًا بثلاث معالجات صورة مختلفة قبل اعتبار الإطار فاشلًا.
- كشف مسارات الترجمة داخل MKV/MKS وM2TS/MTS/TS بواسطة FFprobe.
- دعم PGS المستقل بصيغتي SUP/PGS وVobSub من نوع IDX/SUB ومشاريع Blu-ray BDN XML/PNG.
- استخراج VobSub المضمّن داخل MKV/MKS تلقائيًا إلى زوج IDX/SUB مؤقت مع الحفاظ على التوقيت.
- التحقق من أول وآخر توقيت VobSub بعد الاستخراج قبل بدء OCR.
- مقارنة عدد أحداث المصدر بعدد الإطارات المحللة ومنع تصدير أي نتيجة ناقصة.
- التفريق بين VobSub الصوري وMicroDVD/SubViewer النصي عند فتح ملفات SUB.
- معالجة PGS وVobSub عبر LM Studio أو Ollama أو خادم Unsloth المتوافق مع OpenAI.
- دعم Unsloth افتراضيًا عبر `http://127.0.0.1:8888/v1` مع مفتاح API مؤقت لا يُحفظ على القرص.
- اكتشاف الموديلات تلقائيًا من LM Studio وOllama وUnsloth والخوادم المتوافقة مع OpenAI.
- الاتصال بمحرك Vision الذي يشغّله المستخدم يدويًا وفحص استجابة API قبل المعالجة.
- لا يشغّل التطبيق LM Studio أو Ollama أو Unsloth ولا يوقف أي برنامج خارجي.
- تفضيل موديلات Vision وإخفاء الموديلات النصية المؤكدة من قائمة الاختيار.
- تخزين دائم في SQLite واستئناف آمن حسب بصمة الملف والمسار والموديل.
- تمييز أخطاء API عن الصور الفارغة، واعتبار رد `EMPTY` على صورة غير فارغة فشلًا بدل إسقاط السطر بصمت.
- عدم اعتماد الملف النهائي كمكتمل ما دامت هناك إطارات فاشلة.
- حفظ النص المنجز في ملف `.partial` عند وجود إطارات فاشلة حتى لا يضيع تحويل طويل.
- عدّ إطارات PGS القابلة للرسم فعليًا بدل سجلات PCS الخام التي قد تتضمن حدثًا بلا صورة.
- استخدام لغة المسار كتلميح تعرف فقط دون ترجمة النص أو إعادة صياغته.
- حساب عدد إطارات PGS مسبقًا لعرض تقدم فعلي ووقت متبقٍ أكثر دقة.
- تضمين ملفات IDX/SUB المرافقة وصور BDN في بصمة الاستئناف لمنع استخدام نتائج قديمة.
- تصدير ذري إلى SRT وVTT وASS وTXT.
- إيقاف مؤقت وإلغاء آمن مع حفظ التقدم.

## صيغ الترجمة الصورية

| النوع | المصدر | الحالة |
|---|---|---|
| PGS | MKV/MKS وM2TS/MTS/TS | استخراج وتحقق زمني |
| PGS | SUP/PGS مستقل | قراءة مباشرة بالتوقيت الأصلي |
| VobSub | MKV/MKS | استخراج IDX/SUB عبر MKVToolNix والتحقق من التوقيت |
| VobSub | IDX/SUB مستقل | قراءة مباشرة بالتوقيت الأصلي |
| BDN | XML مع صور PNG | قراءة Timecode والصور مباشرة |
| DVB Subtitle | TS/M2TS/MKV والحاويات المدعومة | فك صور مباشر عبر PyAV مع PTS الأصلي |
| XSUB | AVI/DivX والحاويات المدعومة | فك صور مباشر مع توقيت XSUB الداخلي |
| DVD Video | مجلد VIDEO_TS أو IFO/VOB | اختيار رقم Title وقراءة IFO/NAV عبر FFmpeg dvdvideo |

يتطلب DVB Subtitle وXSUB وDVD اعتماد PyAV الموجود في `requirements.txt`. عند اختيار DVD يطلب
التطبيق رقم العنوان (Title) لأن القرص قد يحتوي الفيلم والإضافات في عناوين منفصلة.

يتطلب VobSub المضمّن توفر `mkvmerge` و`mkvextract` من MKVToolNix. لا تعرض الواجهة مسارات
هذه البرامج؛ تظهر رسالة مباشرة إذا كانت الأداة المطلوبة غير متوفرة.
