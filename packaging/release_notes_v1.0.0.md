# OCR-AI Studio 1.0.0

الإصدار الأول من OCR-AI Studio لتحويل الترجمات الصورية إلى ملفات نصية دقيقة مع الحفاظ على توقيت المصدر.

## الخصائص

- واجهة عربية RTL من صفحة واحدة مع السحب والإفلات.
- دعم PGS وVobSub وBDN وDVB Subtitle وXSUB ومجلدات DVD.
- دعم LM Studio وOllama وUnsloth والخوادم المتوافقة مع OpenAI API.
- اختبار أول ثلاث صور قبل متابعة التحويل الطويل.
- قائمة انتظار دائمة لعدة ملفات مع الاستئناف التلقائي.
- حفظ ملف `.partial` دوريًا أثناء العمل.
- إعادة محاولة الصور الفاشلة بمعالجات صورة مختلفة.
- فحص التوقيت قبل اعتماد الملف النهائي.
- تصدير SRT وVTT وASS وTXT.
- عرض عدد الصور والأسطر والوقت المنقضي والمتبقي.

يشغّل المستخدم محرك Vision والموديل يدويًا، ثم يفحص التطبيق الاتصال ويجلب موديلات Vision.

اجتاز الإصدار 70 اختبارًا آليًا وفحص Ruff الكامل.
