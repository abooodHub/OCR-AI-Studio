# OCR-AI Studio 2.0.0 Alpha 2

إصدار تطويري يضيف إدارة احترافية لمحركات الذكاء الاصطناعي المحلية وتحسينات شاملة للواجهة.

## أبرز التغييرات

- اكتشاف LM Studio وOllama وUnsloth تلقائيًا.
- تشغيل الخادم المحدد عند الحاجة وانتظار جاهزية API قبل بدء التحويل.
- لوحة حالة مباشرة تعرض التثبيت والاتصال وملف التشغيل وملكية العملية.
- عدم إيقاف أي خادم بدأه المستخدم أو برنامج آخر.
- دعم اختيار ملف تشغيل مخصص وحفظه لكل مزود.
- بطاقات مزودين تفاعلية بتصميم RTL وأيقونات موحدة.
- تحسين معلومات التقدم وسجل المعالجة والحركات البصرية.
- تنظيم جميع صور الواجهة داخل `assets/app` و`assets/providers`.

> تتطلب معالجة ملفات الوسائط توفر FFmpeg وFFprobe على جهاز المستخدم.
