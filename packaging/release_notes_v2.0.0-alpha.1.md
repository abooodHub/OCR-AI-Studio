# OCR-AI Studio 2.0.0 Alpha 1

إعادة بناء كبيرة للبرنامج مع واجهة عربية RTL ومحرك معالجة أكثر أمانًا.

## أبرز المزايا

- دعم LM Studio وOllama وUnsloth وOpenAI-compatible.
- اكتشاف الموديلات وحالة التحميل وVision تلقائيًا.
- دعم PGS وملفات SUP المستقلة وVobSub من نوع IDX/SUB.
- استخراج المسارات النصية مباشرة من MKV/MKS.
- تصدير SRT وVTT وASS وTXT.
- حفظ مشاريع SQLite والاستئناف بعد الإلغاء.
- منع تصدير ملف فارغ أو ناقص كأنه ناجح.
- ملف Windows EXE واحد مع أيقونة وبيانات إصدار.

## متطلبات نسخة Windows

- Windows 10 أو Windows 11 بنظام 64-bit.
- تثبيت FFmpeg وFFprobe وإضافتهما إلى PATH.
- تشغيل أحد خوادم Vision المدعومة واختيار موديل يقبل الصور.

## ملاحظات Alpha

- FFmpeg غير مرفق داخل EXE في هذا الإصدار.
- مسارات DVD/VobSub المضمنة مباشرة داخل MKV/MKS لا تزال تحتاج استخراجها أولًا إلى IDX/SUB.
- قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقميًا.
